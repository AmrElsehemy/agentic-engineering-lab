# Contributing

Thanks for helping improve the Agentic Engineering Lab.

## Before opening an issue

- Search existing issues first.
- Include the example, commit or release version, environment, and exact error.
- Never include credentials, confidential data, or personal health information.

## Before opening a pull request

- Explain the problem and the smallest useful change.
- Update the relevant documentation.
- Include tests or a reproducible validation path where practical.
- State known limitations and follow-up work.
- Keep the pull request focused on one pattern or improvement.

## Discussion standard

Be precise, constructive, and generous. The purpose of this lab is to make agent systems more understandable and reliable, not to promote a single framework or claim a universal best practice.
