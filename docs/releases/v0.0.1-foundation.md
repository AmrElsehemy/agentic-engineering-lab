# v0.0.1-foundation

This foundation release establishes the public lab structure and the first deterministic production-pattern examples.

Included:

- Single agent with a bounded tool call
- Explicit routing with human-review fallback
- Human-in-the-loop approval state machine
- Dependency-free evaluation checks
- Architecture decision record and architecture map
- GitHub Actions deterministic checks

This is not the full v0.1 release. The Foundry-specific live run, deeper evaluation, observability evidence, and release-level onboarding remain follow-up work.
