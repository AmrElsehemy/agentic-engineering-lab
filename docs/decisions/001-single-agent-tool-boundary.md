# ADR 001: Start with a single agent, a read-only tool and one approval-gated tool

- **Status:** Accepted
- **Date:** 2026-10-02 (revised after the first live trace)
- **Scope:** example 01, first implementation

## Decision

Start with a single model-driven agent that chooses between two locally executed tools:

- `get_training_plan`: read-only, deterministic.
- `save_plan`: a side effect (appends to a local file). It runs only after a human approves, the plan content is regenerated by the application and never taken from model output, and approval is requested only after arguments validate.

The model decides whether to call a tool (`tool_choice=auto`). Forcing the call, as the first version did, made the loop a scripted function call, not an agent decision. The loop is bounded (`MAX_STEPS`) and the last step runs with `tool_choice=none`.

## Why

A small loop makes the most important production boundaries visible:

- tool schema and input validation
- model-to-tool handoff
- tool result handling
- unknown-tool blocking
- separation of planning from side effects
- future evaluation and tracing points

## Alternatives rejected

- **Multi-agent first:** adds coordination complexity before the basic loop is understood.
- **Autonomous external actions:** introduces side effects and authorization concerns too early.
- **Framework-heavy abstraction:** hides the underlying protocol we need to inspect and teach.

## Security boundary

- Allowlisted tools only; unknown tools are returned to the model as errors, not executed.
- Malformed, extra or missing arguments are returned to the model as errors, not raised.
- One tool call per turn; extra calls are skipped with an error result.
- Side effects need explicit approval; with no interactive terminal the answer is no.
- Traces redact arguments, results and content unless `FOUNDRY_TRACE_CONTENT=true`.
- Credentials are never passed to the model or committed to the repository.

## Follow-up

Add Foundry-hosted evaluation, durable audit storage, and a real authorization model for approvers before any production use.
