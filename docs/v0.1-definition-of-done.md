# v0.1 Definition of Done

Target release: **8 October 2026**

## Repository

- [ ] README explains the purpose, audience, scope, and responsible-use boundaries
- [ ] At least one tagged release exists
- [ ] Repository structure is understandable to a new contributor
- [ ] Setup steps are tested from a clean environment

## Examples

- [ ] Single-agent example is runnable
- [ ] Tool-calling example is runnable or has an explicit documented blocker
- [ ] Routing example is runnable or has an explicit documented blocker
- [ ] Human-in-the-loop or basic multi-agent example is runnable or has an explicit documented blocker

## Technical quality

- [ ] Architecture decision is documented for each example
- [ ] Failure modes and limitations are documented
- [ ] Secrets and sensitive data are excluded
- [ ] Evaluation questions or criteria are identified
- [ ] Observability requirements are identified

## Public proof

- [ ] Release notes are published
- [ ] A technical article or build note links to the repository
- [ ] A short walkthrough is recorded or scheduled
- [ ] Public feedback is invited through Issues
